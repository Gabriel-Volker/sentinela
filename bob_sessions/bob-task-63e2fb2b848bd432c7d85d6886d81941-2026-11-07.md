def _cliente_negou(respostas: list[dict]) -> bool:
    """Retorna True se a última resposta do cliente contiver negativa clara."""
    if not respostas:
        return False
    ultima = respostas[-1]
    if ultima.get("sem_resposta"):
        return False
    texto = (ultima.get("texto") or "").lower().strip()
    if not texto:
        return False
    # Começa com "não"/"nao"
    if texto.startswith("não") or texto.startswith("nao"):
        return True
    return any(p in texto for p in _PALAVRAS_NEGATIVA)

- Se o único JSON encontrado for o retorno de `executar_decisao` (`status + desfecho` sem `evidencias`/`justificativa`), reconstrói um dict mínimo compatível com `RespostaValidacao` para não perder a decisão.

**`fraude/coordenador.py` — funções `_sanitizar_analise` e `_sanitizar_validacao`:**
- Filtram os dados brutos do LLM mantendo **somente** as chaves permitidas por cada contrato antes do parse Pydantic — elimina `"execucao"`, `"hash_validacao"`, e qualquer outra chave inventada pelo modelo.

- Para desfechos finais (`autorizar/bloquear/pendente`), forçam `pergunta=None` (evita erro em caso de string vazia).

**`_fallback_validacao_pendente` — mensagens limpas + detecção de negativa:**
- Nunca mais expõe `1 validation error for RespostaValidacao...` na UI.
- Se a última resposta do cliente contiver negativa clara ("não fui eu", "fraude", "roubado", começa com "não"…), aplica **`BLOQUEAR`** com justificativa em português. Caso contrário, aplica `PENDENTE`.
